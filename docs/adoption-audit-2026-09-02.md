# Public adoption audit — 2026-09-02

## Verdict

There is no defensible evidence yet that GraceGraph, GraceLoop, or
CausalFrontier has meaningful external scientific use. Public availability is
verified; adoption, independent reproduction, user value, and impact are not.

This is a read-only snapshot of GitHub's repository, traffic, release, issue,
and pull-request APIs queried on 2026-09-02 at approximately 05:15 UTC. GitHub
traffic covers a rolling 14-day window and is visible only to sufficiently
authorized repository users. It is not a lifetime-use metric.

Release assets showed only approximately one to three downloads each. There
were no open human-authored issues. GraceGraph and GraceLoop each had four open
Dependabot pull requests; automated dependency activity is not user adoption.

## Interpretation boundary

Clone counts cannot be attributed to independent scientists. They may include
the maintainer, CI, dependency automation, security scanners, repeated setup,
or other machine traffic. One unique page viewer does not establish a user, and
a download does not establish installation, completion of a workflow, or value.
Stars and forks are also weak proxies, but zeros across all three repositories
remove even that limited public signal.

Accordingly, none of these metrics supports claims of:

- an active user, laboratory, or contributor community;
- an independent installation or reproduced result;
- time or cost saved in a scientific workflow;
- a decision-relevant falsification reached;
- a scientific discovery, paper, clinical benefit, or life saved; or
- product-market fit, broad impact, or journal interest.

## Consequence

The next program milestone should measure use rather than optimize publicity:
an independently observed novice installation and one complete read-only task,
with setup failures, human time, compute, direct cost, abstentions, and the next
decision-relevant action recorded. Recruitment or outreach requires separate
authorization. Until then, public code should be described as available and
unvalidated—not adopted.
