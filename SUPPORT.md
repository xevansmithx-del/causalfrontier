# Support

## Where to ask

- Source-tree pilot results: use the **External source-tree reproduction** issue
  template.
- Reproducible defects: open a public issue with the smallest synthetic example,
  exact commit or release, environment, command, and observed output.
- Feature or protocol proposals: open a focused issue describing the scientific
  failure mode and the gate that would test the change.
- Security-sensitive reports: follow [SECURITY.md](SECURITY.md) and use GitHub
  private vulnerability reporting.

Do not post credentials, patient information, private research records,
restricted datasets, unpublished outcome material, or unpatched exploit details
in a public issue.

## Scope

Support covers installation, documented public interfaces, synthetic fixtures,
capsule verification, and reproducible software defects. It does not provide
patient advice, clinical interpretation, wet-lab instructions, material
authorization, causal conclusions, or a promise that a case is scientifically
valid.

## Service level

CausalFrontier is maintained on a best-effort basis. There is currently no
guaranteed response time, compatibility window, or commercial support channel.
