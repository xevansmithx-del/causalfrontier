# Changelog

All notable changes to CausalFrontier are documented here.

## 0.1.0-alpha.1 — 2026-08-28

- Add strict frozen-case inventories, declared competing causal worlds, one required
  open-world residual, complete outcome matrices, and branch-plan digests.
- Add prior-free Pareto and informative-branch-conditional minimax frontiers over
  decision-equivalence classes.
- Add contradiction, execution-failure, and no-call branches plus declared gates and
  source-authority checks.
- Add digest-bound synthetic classifiers with exact input schemas, deterministic
  failure precedence, closed outcome maps, exact declared-group checks, and semantic
  result replay.
- Add no-clobber capsules, exact replay, and a hash-chained local rehearsal ledger with
  external-head compare-and-swap support.
- Fix the pre-alpha boundary at zero prospective benchmark cases and zero prospective
  experiments, with no clinical, material, or human-decision authority.
- Include one original synthetic, network-free aggregate fixture and hostile tests.
- Add privacy checks, exact source-manifest verification, packaging, CI, CodeQL, and a
  prerelease workflow.
